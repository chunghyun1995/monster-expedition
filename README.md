# 몬스터 원정대 (Monster Expedition) v2

휴대용 게임기 감성의 **2화면 턴제 몬스터 RPG**입니다. 브라우저에서 바로 플레이할 수 있고, 배포용 게임 전체가 `index.html` 파일 하나에 들어 있습니다.
등장하는 몬스터·기술·인물·음악·도트와 몬스터 능력치·도감 설명은 모두 이 프로젝트를 위해 새로 만든 오리지널입니다.

▶ 플레이: GitHub Pages 주소 (`https://<아이디>.github.io/monster-expedition/`)

📱 안드로이드 앱: [최신 APK 내려받기](https://github.com/chunghyun1995/monster-expedition/releases/latest) (Android 7.0 이상, Android 12 · 13 · 14에서 테스트) — 아래 [안드로이드 앱(APK)](#안드로이드-앱apk) 참고

## 조작

| 동작 | 키보드 | 모바일 / 터치 |
| --- | --- | --- |
| 이동 | 방향키 / WASD | 방향 패드 |
| 달리기 | X(B)를 누른 채 이동 | B를 누른 채 이동 |
| 확인 · 대화 · 조사 | Z / Space | A 버튼, 아래 화면 버튼 터치 |
| 취소 | X / Backspace | B 버튼 |
| 메뉴 | Enter / Esc / C | MENU 버튼, 아래 화면 “메뉴” |
| 원정패드 앱 전환 | Q / E | 패드 양옆 ◀ ▶ |
| 소리 켜기/끄기 | M | — |

방향을 짧게 누르면 제자리에서 방향만 바뀌고, 길게 누르면 걸어갑니다.

## 위 화면 / 아래 화면

- **위 화면**: 필드, 배틀 연출, 대화창, 각종 정보 페이지
- **아래 화면(터치)**: 원정패드(시계·파티·지도·만보기), 메뉴, 배틀 명령, 기술 선택, 가방, 파티, 도감 목록, 상점 등

## 이야기

새싹마을에서 한결 박사에게 첫 파트너(불똥이 · 물방울 · 새싹콩 중 하나)를 받고, 라이벌 도윤과 경쟁하며 다섯 개의 체육관에 도전합니다.

새싹마을 → 바위시티(관장 단단) → 물결마을(관장 하라) → 3번 화산길 → 붉은재마을(관장 화련) → 4번 도로 → 번개도시(검은안개단에게 점령당한 발전소 탈환, 관장 찌나) → 5번 산길 → 하늘봉마을(관장 하늬) → 정상에서 라이벌과의 마지막 승부 → 엔딩

## 게임 시스템

- 몬스터 34종 (3단 진화 계열·전설의 몬스터 포함), 10가지 타입과 상성, 이중 타입
- 기술 48종: 물리 / 특수 / 변화 분류, 명중률, PP, 우선도, 급소, 흡수, 반동, 풀죽음, 능력 변화
- 6가지 능력치(체력·공격·방어·원소공격·원소방어·속도), 개체마다 다른 잠재 능력, 성격 12종, 반짝이(★, 색이 다른 개체)
- 상태 이상: 독 · 화상 · 마비 · 잠듦
- 포획: 남은 HP·상태 이상·캡슐 종류에 따른 포획률, 캡슐 흔들림 연출, 도감 신규 등록, 닉네임
- **몬스터 빼앗기**: 상대 트레이너의 몬스터도 캡슐로 잡을 수 있음. 잡으면 내 몬스터가 되지만 “이런 미친놈! 뭐하는 짓이야!” 하며 화가 난 트레이너가 직접 전투에 뛰어듦(주먹·날아차기·회복약, 도망 불가). 트레이너를 쓰러뜨리면 그대로 내 것, 내 몬스터와 나까지 쓰러지면 빼앗은 몬스터를 되찾아 감
- 경험치 분배, 레벨업 능력치 상승 창, 기술 4개 제한과 교체, 진화(B로 취소 가능)
- 트레이너 시야 · 느낌표 연출, 상대 교체 시 “교체/연속” 전투 방식, 관장의 회복약 사용, 상금, 전멸 시 귀환
- 실내 맵(집·연구소·몬스터 쉼터·상점·민가·체육관 2곳), 턱 점프, NPC 배회, 실제 시간에 따른 낮·밤 색감
- 메뉴: 도감 · 몬스터 · 가방(주머니 3개) · 트레이너 카드(배지 케이스) · 리포트(저장) · 설정
- 몬스터 쉼터 회복 연출, PC 보관함, 상점 사기/팔기와 수량 선택
- 몬스터 합성: 아무 몬스터 두 마리 → 한 단계 위 등급(기본→1진화→최종진화)의 무작위 타입 몬스터(높은 쪽 레벨 +2). 메뉴 → 몬스터 → 합성하기, 또는 몬스터 쉼터 합성 연구원
- 저장 코드: 리포트에서 "기록하고 저장 코드 만들기" → ① 옆 기기 카메라로 QR 찍기(게임이 열리며 바로 불러오기) 또는 ② 코드·링크 복사 → 다른 기기 타이틀의 "코드로 불러오기"에 붙여 넣기
- 최후의 수단: 몬스터가 모두 쓰러지면 한 번, 트레이너가 직접 맞서 싸울 수 있음(돌 던지기 · 몸통 박치기 · 회복약 · 도망/버티기)
- 레벨업 물약(상점 350원), 야생 몬스터를 쓰러뜨리면 얻는 경험치의 50%만큼 돈 획득, 보관함에 맡긴 몬스터는 10분마다 레벨 +1(파티 최고 레벨까지)
- 대화창 초상화: 곡선으로 그린 인물별 애니메이션풍 일러스트(눈 깜빡임, 말할 때 입 움직임)
- 기술 48종마다 고유한 연출(광선·할퀴기·음표·해일·낙뢰·바위사태·급강하·거미줄 등)
- **무한의 탑**: 원정패드를 받은 뒤부터 필드 오른쪽 위 '탑' 버튼으로 어디서든 입장(나오면 원래 자리로), 1~100층, 수호자 레벨 = 층수, 10층마다 회복·보상·체크포인트, 100층은 레벨 100 몬스터 6마리)
- **자동 전투**(효과가 굉장한 공격 기술 우선, 없으면 가장 센 공격 기술) · **자동 사냥**(풀숲을 오가며 전투, 체력 35% 미만이면 정지) · **탑 자동 등반**(지면 정지), 아무 키나 '자동 중지'로 멈춤
- 엔딩 이후: **전설의 몬스터** — 하늘봉 장로에게 이야기를 듣고 세 수호신(염화룡 · 심해왕 · 뇌명조)의 동굴을 찾아가면, 정상에 하늘의 신 천공신이 나타남. 황금캡슐(엔딩 후 상점 판매)
- 숨겨진 요소: 연구소에서 캡슐 셋을 모두 거절해 보세요
- 처음 쓰는 기능마다 말풍선 안내(설정 → 안내 툴팁에서 끄기 / 처음부터 다시 보기)
- 2배 정밀 도트: 48×48 몬스터(디더링 명암·색 외곽선·눈 하이라이트), 인물 자동 외곽선·명암, 반 픽셀 타일 디테일
- 칩튠 BGM 13곡과 팡파르, 효과음, 종마다 다른 울음소리 (Web Audio로 실시간 합성)

## 안드로이드 앱(APK)

웹 게임(`index.html`)을 그대로 담은 안드로이드 앱입니다. 인터넷 없이도 실행되고(글꼴까지 앱에 내장), 게임 내용은 웹 버전과 같습니다.

**설치**

1. 휴대폰에서 [Releases](https://github.com/chunghyun1995/monster-expedition/releases/latest)의 `monster-expedition.apk`를 내려받아 엽니다.
2. "출처를 알 수 없는 앱" 설치를 허용하라는 안내가 나오면 허용합니다.
3. 새 버전은 지우지 말고 **그대로 덮어 설치**하세요. 리포트(세이브)가 유지됩니다.

**지원 버전**: Android 7.0(API 24) 이상. `targetSdk 35`. 빌드할 때마다 Android 12(API 31) · 13(API 33) · 14(API 34) 에뮬레이터에 설치해 실행, 뒤로 가기, 저장 유지를 자동으로 확인합니다.

| 항목 | 앱에서의 동작 |
| --- | --- |
| 화면 | 상태 표시줄·내비게이션 바를 숨긴 전체 화면, 카메라 구멍(컷아웃)과 키보드 영역은 비워 둠, 가로·세로 회전해도 진행 유지 |
| 뒤로 가기 | B(취소) 버튼. Android 13 이상은 새 뒤로 가기 방식(OnBackInvokedCallback) 사용 |
| 소리 | 볼륨 키로 조절, 앱을 벗어나면 멈추고 돌아오면 다시 재생 |
| 리포트 | 앱 안(WebView localStorage)에 저장. 웹 버전과 세이브는 따로이며, 저장 코드로 서로 옮길 수 있음 |
| 저장 코드 복사 | 안드로이드 클립보드로 바로 복사 |
| 기타 | 자동 사냥 중 화면 꺼짐 방지, Android 12+ 게임 앱으로 등록, Android 13+ 테마 아이콘 |

**직접 빌드**: Android Studio로 `android/` 폴더를 열거나, JDK 17과 Android SDK가 있으면

```
cd android
./gradlew assembleRelease   # → android/app/build/outputs/apk/release/app-release.apk
```

빌드할 때 저장소 맨 위의 `index.html`이 앱에 자동으로 들어가므로, 게임을 고친 뒤 `python3 build.py`만 하면 됩니다. `main`에 `index.html`이나 `android/`의 변경이 올라가면 GitHub Actions(`.github/workflows/android.yml`)가 APK를 빌드·테스트하고 Releases에 새 APK를 올립니다.

**서명 키**: Releases에 올라가는 APK는 저장소에 올리지 않은 개인 키로 서명합니다. GitHub Actions는 저장소 시크릿 4개(`ME_KEYSTORE_BASE64` 키 파일 base64, `ME_KEYSTORE_PASSWORD`, `ME_KEY_ALIAS`, `ME_KEY_PASSWORD`)로 키를 받고, 시크릿이 없으면 빌드를 멈춥니다. 로컬에서 같은 키로 서명하려면 환경 변수 `ME_KEYSTORE_FILE`(키 파일 경로)과 비밀번호·별칭 변수를 지정하세요. 지정하지 않으면 배포용은 서명 없이(`app-release-unsigned.apk`), 디버그용은 Android 기본 디버그 키로 만들어집니다. 키 파일과 비밀번호를 잃어버리면 같은 앱으로 업데이트를 낼 수 없으니 꼭 백업해 두세요.

> APK 13 이하(apk-1 ~ apk-13)는 예전 공용 키로 서명돼 있어서 새 APK를 덮어 설치할 수 없습니다. 그 버전을 쓰고 있다면 리포트 → 저장 코드로 진행을 옮겨 둔 뒤, 앱을 지우고 새로 설치해 저장 코드로 불러오세요.

## 프로젝트 구조

```
index.html        ← 배포용 (빌드 결과물, 이 파일 하나로 실행)
build.py          ← src/를 묶어 index.html 생성
src/
  shell.html      HTML 뼈대
  style.css       2화면 셸과 UI 스타일
  core.js         유틸, 설정, 입력, 화면 크기
  audio.js        BGM 시퀀서, 효과음, 울음소리
  data.js         타입·기술·몬스터·도구·성격·트레이너
  mon.js          개체 생성, 능력치 계산
  gfx.js          도트 생성(몬스터·인물·타일), 전투 배경, 파티클, 아이콘
  ui.js           대화창, 터치 버튼 패널, 리스트, 예/아니오, 수량, 이름 입력
  maps.js         지도와 이벤트 스크립트
  menus.js        원정패드와 모든 메뉴 화면
  battle.js       배틀과 진화
  world.js        필드 이동, 타이틀·오프닝·엔딩, 메인 루프
android/          안드로이드 앱(APK) 프로젝트
  app/src/main/   MainActivity(전체 화면 WebView), 매니페스트, 아이콘
  fonts/          앱에 내장하는 Galmuri 글꼴(OFL)
  ci/             에뮬레이터 테스트 스크립트
```

수정한 뒤에는 `python3 build.py`로 `index.html`을 다시 만들고 커밋하면 GitHub Pages에 반영되고, `main`이면 새 APK도 Releases에 올라갑니다.
