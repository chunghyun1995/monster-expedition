# 몬스터 원정대 (Monster Expedition)

오리지널 몬스터를 모으고 키우는 턴제 RPG입니다. 설치 없이 브라우저에서 바로 플레이할 수 있고, 게임 전체가 `index.html` 파일 하나에 들어 있습니다.

## 플레이 방법

| 동작 | 키보드 | 모바일 |
| --- | --- | --- |
| 이동 | 방향키 / WASD | 화면 아래 방향 패드 |
| 확인 · 대화 · 조사 | Z / Enter / Space | A 버튼 |
| 메뉴 · 취소 | X / Esc | B 버튼 |
| 소리 켜기/끄기 | M | 하단 버튼 |

**목표:** 새싹마을에서 첫 파트너를 받아 1번 도로를 지나 바위시티 체육관의 관장 단단을 이기면 클리어입니다. 클리어 후에도 도감(17종)을 채우며 계속 플레이할 수 있습니다.

## 게임 내용

- 맵 4곳: 새싹마을 · 1번 도로 · 바위시티 · 2번 도로(숲)
- 몬스터 17종, 타입 8종(노말·불·물·풀·전기·바위·비행·벌레)과 상성
- 풀숲 랜덤 인카운터, 포획캡슐로 포획, 파티 6마리 + 보관함
- 레벨업, 기술 습득(4개 제한·교체), 진화
- 시야에 들어오면 다가오는 트레이너 4명, 체육관 관장전(클리어 후 재대전 가능)
- 상점, 몬스터 센터, 집에서 회복, 전멸 시 소지금 절반을 잃고 회복 장소로 복귀
- 도감, 몬스터 정보 화면, 브라우저 저장(localStorage) / 이어하기
- 효과음(Web Audio), 도트 그래픽은 모두 코드로 그려서 외부 이미지 파일이 없음

## GitHub Pages로 배포하기

1. 이 저장소의 **Settings → Pages**로 이동합니다.
2. **Build and deployment → Source**를 `Deploy from a branch`로 두고, Branch를 `main` / `/ (root)`로 선택한 뒤 **Save**를 누릅니다.
3. 1~2분 뒤 `https://<GitHub 아이디>.github.io/<저장소 이름>/` 주소에서 플레이할 수 있습니다.

로컬에서는 `index.html`을 브라우저로 열기만 하면 됩니다.
