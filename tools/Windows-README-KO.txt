벨로리아 생태기록 / VELORIA FIELDNOTES — Windows x64

압축을 모두 풀고 VeloriaFieldnotes.exe를 실행하세요.
VeloriaFieldnotes.pck는 실행 파일과 같은 폴더에 있어야 합니다.
이 실행 파일은 별도 설치 프로그램이 아닌 시험용 직접 실행판입니다.

조작: 방향키/WASD 이동, Z/Enter/Space 결정·조사,
X/Esc 취소, C/M/Tab 메뉴. 마우스로 화면 버튼도 사용할 수 있습니다.
Windows 10 1809 이상 / Windows 11 x64, OpenGL 3.3 지원 그래픽 장치가 필요합니다.
Xbox 콘솔용 빌드는 아닙니다.

MS Store 업로드에는 -STORE.msix 파일을 사용합니다.
이 파일은 Partner Center 제출용 미서명 패키지이며 직접 더블클릭 설치용이 아닙니다.
Microsoft Store는 인증 후 패키지에 서명합니다. 제출용 MSIX를 위해 유료 인증서를 구매할 필요는 없습니다.

앱 안의 메뉴 → 설정 → 라이선스에서 Godot 엔진, 폰트 및 포함 구성요소의 고지를 볼 수 있습니다.
