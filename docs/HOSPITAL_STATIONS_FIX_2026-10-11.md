# 병원 복귀와 관측소 수정

기준: veloria-82 (`fb26a4f8aa9c445221879f95d432d370202bfd00`)의 게임 소스와 최신 main `daf54d577d4983077b9c92d130ba9cf18b5bd9c4`. 두 커밋의 게임 코드는 동일하며 main의 추가 스토어 스크린샷을 보존했다.

## 변경

- 다섯 치료 시설의 지도 이름·건물 이름판·주민 대사·의무원 안내를 ‘병원’으로 통일.
- 돌기둥마을부터 마을에 도착하면 병원을 복귀 지점으로 등록. 치료를 받은 적이 없어도 전투 패배 후 병원 접수대 앞(6,4)에서 회복한다.
- 이동 중에는 최근 방문한 마을의 병원을 유지. 기존 일지는 현재 마을·실내·길·동굴에 맞는 지역 병원을 사용한다. 초기 마을로 돌아가 집에서 쉬어도 병원 등록을 잃지 않는다.
- 처음 마을의 집/연구소 복귀와 최초 동료 점검 전투는 유지. 무한의 탑의 전용 패배/퇴장 처리는 유지.
- 다섯 관측소 실내를 13×16칸에서 8×7칸으로 축소. 현장 책임자 한 명만 남기고 안내원·추가 원정가·미로·단상·동상·조사 오브젝트 제거. 외관도 3×3칸으로 축소.
- 관측소 책임자 전투·인증·진행 조건을 유지하고 출입 위치를 수정. 이전 크기의 관측소 안에서 저장한 위치가 막히거나 방 밖이면 새 입구로 이동한다.
- Godot 데이터 생성 도구에도 수정 반영. 재생성 시 옛 지도 구성이 복원되지 않는다. 기존 지도 ID·진행 플래그·Android 패키지/서명·Store ID는 유지한다.

## 확인

- veloria-82 MSIX를 내려받아 매니페스트와 실제 실행 파일 확인. Store ID는 CH.KIM.41446B34EC3C8, Publisher는 CN=E3DEBC8C-0962-4B33-96EF-73F9184A22D9. 서명 없는 Store 제출용 패키지이므로 로컬 설치 대신 내부 EXE를 Windows 11에서 실행하고 NVIDIA OpenGL 렌더링 화면을 확인했다.
- `res://tests/hospitals.tscn`: 다섯 마을의 실제 패배 → 병원/전원 회복, 기존 일지, 집으로 돌아갔을 때 등록 보존, 축소 지도 안전 위치/책임자 접근/승리 인증/출구, 길의 복귀 지점 검증 (`HOSPITALS_PASS`).
- 기존 전체 검사 `res://tests/regression.tscn`: `GODOT_REGRESSION_PASS`.
- 관측소 1·5, 병원 접수대, 돌기둥마을 외관의 수정 화면을 Windows 11 네이티브 렌더링으로 확인.
- 새 병원 검사 종료 시 엔진의 객체/리소스 정리 경고가 출력되지만 스크립트 오류나 검증 실패는 없다. CI는 PASS 마커와 스크립트 오류 유무를 모두 확인한다.

출시 파일은 GitHub Actions에서 APK/AAB 기존 키 서명, Android 16 실행 확인, Windows 실행과 임시 서명 사본 설치 확인 후 생성한다. 게시하는 MSIX는 Microsoft Store 제출용 무서명 파일이다.
