# 벨로리아 생태기록 — 표현 개정 기록

기준: godot-41과 동일한 게임 데이터의 main 5e496dd8. 2026-10-11에 사용자 요청으로 수정했다.

## 변경한 표현

- 제목을 벨로리아 생태기록 / VELORIA FIELDNOTES로 변경. Android 패키지 ID는 기존 업데이트 호환을 위해 유지한다. 이름의 검색 확인은 정식 국내외 상표 조사와 다르다.
- 박사의 세계 소개, 생물 시연, 주인공 축소와 집에서 시작하는 연출을 현장 의뢰 접수·폭풍 이후 관측망 복구 브리핑으로 교체했다.
- 첫 동료는 불·물·풀의 상성 선택이 아닌 정찰·수변·지반 조사 역할이다. 원정 동료는 선택한 생물의 상성 우위 종을 받지 않는다.
- 지역 책임자와의 대결은 관측 센서 보정 훈련이다. 기존 세이브의 `badges` 필드는 호환을 위해 유지하지만 화면의 증표는 관측망의 전자 기록으로 변경했다.
- 공명등은 청록·구리색의 비구형 현장 장비다. 포획 연출은 생물이 보이는 상태에서 선형 신호와 연속 게이지를 조율한다. 흡수·축소·구형 캡슐의 네 번 흔들기 및 해당 확률 공식은 제거했다.
- #13 꽃잠주머니, #22 불꽃담비, #33 자계수는 새로운 앞/뒤 그림과 설명을 적용했다. 자계수는 새가 아닌 여섯 다리 자계 곤충이다.
- 최초 생성 프롬프트가 없었던 인물 27종은 전원 새 앞/뒤 그림으로 교체했다. 동일한 7×4 인덱스를 유지해 저장 데이터와 인물 배치를 보존한다.
- BGM 13곡과 팡파르 8개를 새로 작성한 악보로 교체했다. 악보는 `assets/SCORE_2026-10-11.json`, 렌더 소스는 `src/audio.js`에 남긴다. 나머지 합성 효과음/울음은 기존 소스 기반으로 다시 인코딩했다.
- Godot 및 폰트 고지에 Android 의존성 목록·Apache 2.0 전문을 추가했다. QR 라이브러리는 Godot APK에 포함되지 않지만 웹 소스에도 MIT 전문을 추가했다.

## 이번 생성 경위

이미지 생성 도구: OpenAI image_gen. 정확히 보관한 프롬프트는 `assets/generated/revision-2026-10-11/PROMPTS.json`에 있다. 인물 앞면을 이번에 생성한 뒤 이를 뒷면 생성의 참조로 사용했다. 생물 시트는 투명 배경 보정 후 패킹했다. 외부 게임 그림을 참조 파일로 제공하지 않았다. 최종 그림의 SHA-256은 같은 디렉터리의 HASHES.json에 기록한다.

사용자 진술: 초기 Claude 제작 시에도 파일을 제공하지 않고 말로 분위기만 요청했다고 밝혔다. 이 진술을 실제 에셋 전체의 비침해 증명으로 해석하지 않는다.

## 확인 범위와 남는 확인 사항

이 개정은 감사에서 확인된 구체적인 표현·출처·고지 문제를 줄이는 작업이며, 법률 의견이나 비침해 보증이 아니다. 기존 지도/배경/가구 그림에는 제작 요약은 있으나 모든 최초 프롬프트의 원문은 남아 있지 않다. 확인된 특정 작품의 복제 근거가 없는 그림은 임의로 침해물이라고 단정하지 않았으며, 이 기록을 과거 제작 증빙으로 소급하지 않는다. 기존 전체 에셋과 추가 생성물의 세계 모든 작품에 대한 유사성 검색, 음악 전문 감정, 국내외 모든 지정상품에 대한 상표 조사까지 완료한 것은 아니다. 스토어 공개 전 필요한 최종 법률 검토와 이름 등록 가능성 확인은 별도다.

Android APK/AAB가 이 문서의 변경 사항을 실제 포함하는지, 서명/targetSdk/16KB 정렬/실행 여부는 릴리스 검증 기록에서 확인한다. 이전 godot-41 배포물이나 Git 이력은 새 빌드로 소급 교체되지 않는다.

## 추가 확인: 체력·성장 표시와 전투 문구

체력/경험치 표시와 속성 상성은 일반적인 기능이다. 그 기능 자체가 특정 게임의 저작권 침해라고 단정하지 않았다. 미국 저작권청의 설명은 아이디어·방법·시스템과 표현을 구분하고 짧은 문구의 보호 제한을 설명하지만, 미국 기준을 한국이나 모든 국가에 그대로 적용하지 않는다. 국내 실질적 유사성 판단도 보호되는 창작적 표현을 비교하는 문제다.

이번 개정에서는 원작을 연상시키는 표현을 줄이기 위해 `효과가 굉장했다`/`효과가 별로인 듯하다`를 상성 우세/저항과 실제 배율로 바꿨다. 적·아군 정보는 상단에 나란히 배치하고, 체력은 청록색 계기, 경험치는 별도의 세로 성장 계기로 변경했다. 기존 녹색 체력/파란색 가로 경험치와 동일한 조합을 유지하지 않는다. 이것은 예방적 디자인 변경이며 기존 바나 짧은 문구가 그 자체로 불법이라는 법률 판단이 아니다.
