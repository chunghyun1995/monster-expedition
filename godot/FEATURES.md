# Godot 기능 복원과 UI 보정

## 처음 사용 안내
- 이동·조사, 메뉴·저장, 달리기, 파티, 요약, 가방, 지도, 도감, 상점, 보관함, 합성, 전투·포획·기술, 트레이너 전투, 진화, 자동 진행, 탑을 처음 사용할 때 안내합니다.
- 확인 버튼 또는 A/B로 닫습니다. 본 안내는 앱의 안내 기록에 저장됩니다.
- 설정 → 처음 사용 안내에서 끄고 켤 수 있습니다. 설정 → 처음 사용 안내 다시 보기로 기록을 초기화합니다.
- 자동 진행 중에는 안내가 끼어들지 않습니다. 자동을 끈 뒤 처음 사용하는 기능에서 볼 수 있습니다.

## 자동전투·자동 진행
- 원정패드를 받은 뒤 필드 상단에서 자동전투, 무한의 탑, 자동 사냥을 사용할 수 있습니다. 전투 중에도 자동전투 버튼이 표시됩니다.
- 자동전투는 PP가 남은 기술 중 상성·위력·명중률을 고려해 공격합니다. PP가 모두 소진되면 최후의 기술을 사용합니다. 필요한 동료 교체와 전투 대화를 자동 처리합니다.
- 자동 사냥은 이동 가능한 풀숲을 찾아 왕복하며 전투합니다. 야생 몬스터가 없는 장소, 이동 가능한 풀숲이 없는 경우, 동료 총 체력이 35% 미만이면 중단합니다. 지도 출구·문·낭떠러지·진행 중인 스토리 트리거를 경로에서 제외합니다.
- 자동 등반은 수호자 전투 후 다음 층으로 이동합니다. 패배해 로비로 돌아가거나 100층을 완료하면 끝납니다.
- 자동 중지 버튼이나 직접 이동/B/메뉴 입력으로 사냥·등반을 중지합니다. 이미 시작한 연출 뒤에는 수동 진행으로 돌아가며 다음 자동 이동을 시작하지 않습니다. 별도로 켜 둔 자동전투 설정은 독립적으로 유지됩니다.
- 기존 기술 유지·이름 붙이지 않기 등 정해진 선택만 자동 답변합니다. 합성·구매 등 알 수 없는 질문은 사람이 선택합니다.
- 개발용 Game.auto_text를 켜는 방식으로 구현하지 않았습니다. 리포트 저장은 메뉴에서 직접 합니다.

## 무한의 탑
- 필드의 무한의 탑 버튼으로 로비에 입장합니다. 로비 안내원에게 체크포인트를 고르거나 자동 등반 버튼으로 시작할 수 있습니다.
- 기존 100층 로스터, 최고 기록, 10층 단위 체크포인트·회복·보상, 100층 보상을 유지합니다.
- 로비 출구는 빠른 입장 직전의 지도·좌표·방향으로 돌아갑니다. 빠른 입장 기록이 없으면 기존 출구 목적지를 사용합니다.

## UI
- 요약 화면의 캐릭터가 정보/능력치/기술 탭 아래에 들어오도록 크기를 보정했습니다.
- 요약·가방·도감·기술 설명은 컨테이너 폭을 따라 줄바꿈하며, 긴 내용은 세로로 스크롤할 수 있습니다.
- 가방 미리보기와 가방 제목에 별도 공간을 예약했습니다.
- 가방 분류 버튼에 더 넓은 폭을 주고, 공통 버튼은 텍스트 길이에 따라 글자 크기를 맞춥니다.

## 검증
Godot 4.7.2 회귀 장면에서 540×1170, 720×1280, 720×1560 화면을 검사합니다. 최초 안내 기록·초기화·끄기, 설명 폭과 버튼 경계, 실제 자동전투 승리, 자동 등반의 전투·층 이동·중지, 탑 입장 및 원래 위치 복귀를 검증합니다. 개발용 테스트 장면은 배포에서 제외됩니다.
